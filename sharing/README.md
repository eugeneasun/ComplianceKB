# Share ComplianceKB

**Project homepage:** https://github.com/eugeneasun/ComplianceKB

Use the PNG for a slide or a quick printed card; use the vector SVG when resizing for print. Both QR codes encode the project homepage directly, with no tracking service or expiring redirect.

Suggested caption: **Paper, poster, dataset & reproducibility materials**

Visitors can read the full manuscript PDF, view the ESS poster, inspect an example requirement, browse the datasets and code, or use **Code → Download ZIP** for the complete repository. The homepage is the preferred shared link because individual file paths may change.

These are static QR codes: if the repository is renamed or made private, access can change. Test with a phone before printing.
