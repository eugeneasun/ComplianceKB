# Security and data handling

Do not commit API keys, access tokens, private company records, credentials, reviewer correspondence, or personal annotation notes. Use process environment variables for paid API calls. Review all new files before publishing; this initial curated copy is not a substitute for reviewing future additions.

ComplianceKB is a research prototype. Source hashes and structural tests cannot establish legal correctness or current regulatory applicability. Do not use an automated answer as a final safety-critical compliance decision.
